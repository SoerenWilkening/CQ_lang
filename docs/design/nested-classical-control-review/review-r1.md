# dm7f.16.1 / p3kd.7.7 — independent R11 round 1

Disposition: changes requested. Analytic source review of the first implementation snapshot; corrections made concurrently by the implementer are for the next round. No builds, tests, lowering executions, suites, fixtures or targeted probes were executed by this reviewer (0/6 probes).

## Findings

1. **P1: defined-input totality requires stabilizing every speculative classical call argument.** `SpeculationSafety.cpp:177–180` initially froze only arguments having an effective outer `noundef` attribute. `totalCall` proves a different proposition: a body is total for defined scalar inputs. An exact pure outer function with a plain `i32 %x` parameter may call a total inner function with `i32 noundef %x`, or itself have a `noundef` return. A guarded `fptosi` result passed to the outer function can be poison on an untaken arm; moving the outer call executes the inner immediate-UB use before any freeze of the outer result. Freeze all potentially undef/poison scalar arguments of an admitted speculative classical call; the accepted inert attributes permit this. The parent accepted this finding and reported a correction.

2. **P1: constant RAUW escapes the function.** `stabilize` initially called `V->replaceAllUsesWith(Frozen)` for all sources, including scalar poison and undef constants. Those are uniqued and can have users in multiple functions or constant expressions. A guarded pure `noundef` call with such an actual argument reaches E4 admission because the actual operand is not audited there. Stabilization would rewrite unrelated functions to a freeze defined in the current function, violating SSA dominance and possibly constant-only user constraints. Local SSA values permit global RAUW within their owning function; constant replacement must be limited to appropriate function-local uses. The parent accepted this finding and reported a correction.

3. **P1: entry-defined literals are absent from the marker set.** `moveBody` marks moved definitions, while data lowering erases marked quantum instructions. Consider `%n = fptosi double %d to i32` in the entry block; a nested classical guard proves `0 < d < 1000` before a quantum arm uses `%r = add i32 %q, %n`. The source is defined at `d=1e30` when the guard is false: the poison `%n` exists but is unobserved. Flattening makes the mixed add execute unconditionally. `%r` is marked but then replaced by a gate, while `%n` was never moved or marked. The add and its adjoint can therefore receive poison. Stabilization needs the literal dependencies of speculative operations, including definitions outside the moved region, or an emission-site record.

4. **P2: new proof traversals reintroduce exponential walks and stack failure.** `totalCall` and `definedWithoutContext` recurse without memoization. For helpers where each `f_i` calls `f_{i+1}` twice, the traversal recurrence is `T(D)=2*T(D-1)+O(1)`. A defined SSA chain `%v_i = add i32 %v_{i-1}, %v_{i-1}` has the same recurrence. Deep acyclic chains also consume one C++ stack frame per level. The owning strict callee proof already uses an iterative memoized traversal precisely because these failures prevent valid programs from receiving a compilation result. These new layers need per-query memoization and iterative postorder, with conservative cycle handling. No stress execution was necessary to establish the recurrence.

5. **P1 acceptance-contract risk: ignored `noreturn`.** Parameter and return attributes are audited, but effective function/call-site `noreturn` is not. A pure scalar body containing a return can still carry `noreturn`; its return violates the attribute when the call executes. An untaken guarded call can be source-defined, while its hoisted call cannot return normally. The strict body predicate only checks br/ret terminator shapes. Speculative totality must reject an effective `doesNotReturn()` contract. This is an analytic contract counterexample, not a measured new acceptance.

6. **P1 alias detection risk: reuse the existing emitted-call owner.** `needsStableUse` initially resolved `getCalledFunction()` before checking gate prefixes. Alias-backed emitted calls are invisible through this accessor. `LiteralIntegrity.cpp:isEmittedRuntimeCallee` already uses the called operand's own `GlobalValue` name and documents a measured inverse-emitter alias hole. Reuse that predicate for identifying literal uses. This review did not execute an alias probe or claim that every alias shape passes every unrelated owner.

7. **R12 maintenance concern:** `inertAttrs` duplicated the whitelist inside `ArmClassify.cpp:freezeDischargesHoistedArg`. One owning attribute predicate should serve both contracts; otherwise future parameter attributes can drift between admission and stabilization.
