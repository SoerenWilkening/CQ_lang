# CQ Lab Report — owner-facing, append-only session record

`labreport.pdf` (built locally, **not committed**) is the human-readable history
of the project: one entry per working session, at most five pages, appended at
session close. It exists so the owner can read progress and the state of the art
without reading `CLAUDE.md`'s dated history blocks or the per-increment notes.

## Rules (the mechanical ones are enforced by `tools/labreport/build.py`)

1. **Non-normative.** An entry records what happened and cites where rules live
   (`CLAUDE.md`, `ROADMAP.md`, PRDs, `bd` ids). It never states a new rule. This
   is deliberate: agent-authored prose has hardened into de-facto rulings before
   (the `fenv` lesson in `CLAUDE.md`), and this document must not be a fourth
   place for that to happen.
2. **Append-only.** A committed entry is sealed by its SHA-256 in
   `MANIFEST.sha256` and never edited again. Corrections are dated errata in a
   later entry. Figures live in `figures/NNN/` and are sealed with entry `NNN`.
3. **≤ 5 pages per entry**, measured from the PDF, not asked. A declared
   exemption (`% labreport-page-budget-exempt: <reason>` on the entry's first
   line) is honoured and printed by the build; none has been needed so far, the
   baseline included.
4. **Measured numbers only.** Every figure in an entry was produced in that
   session, with its command shown. Report only what you ran (Rule 19).
5. **Figures welcome** where they make the entry more readable: TikZ/pgfplots
   from committed data (`figures/NNN/*.dat`, generated by a script under
   `tools/labreport/figures/`) or a committed PDF/PNG. No hand-typed numbers in
   a plot.
6. **Not a ctest gate.** TeX is not a test-suite dependency. The build runs at
   Session Completion (see `CLAUDE.md`), not in `ctest`.
7. **Does not duplicate the handoff.** `HANDOFF_*`/`NEXT_SESSION_PROMPT` files
   are agent-to-agent; an entry links to them and digests for the owner.

## Adding an entry (Session Completion step)

```bash
cp docs/labreport/TEMPLATE.tex docs/labreport/sessions/NNN-YYYY-MM-DD-slug.tex   # next NNN
mkdir -p docs/labreport/figures/NNN                                             # if the entry has figures
tools/labreport/figures/corpus_growth.py docs/labreport/figures/NNN/corpus_growth.dat  # example data
$EDITOR docs/labreport/sessions/NNN-...tex
tools/labreport/build.py            # verify manifest, build, check page budget
tools/labreport/build.py --seal     # when the entry is final: seal it, then commit
open docs/labreport/labreport.pdf
```

`sessions.tex` is regenerated by the build script from `sessions/*.tex`; do not
edit it. TeX Live is at `/Library/TeX/texbin` on this machine (`latexmk`,
`pdflatex`, TeX Live 2025).

## Layout

| Path | What |
|---|---|
| `labreport.tex` | master: preamble, macros (`\labsession`, `\labsessionheader`, finding tags, `\measured`), title, how-to-read, TOC |
| `sessions.tex` | GENERATED list of `\labsession{NNN-...}` lines |
| `sessions/NNN-YYYY-MM-DD-slug.tex` | one sealed entry per session |
| `figures/NNN/` | that entry's data files and images, sealed with it |
| `MANIFEST.sha256` | digests of every sealed file; checked on every build |
| `TEMPLATE.tex` | skeleton for a new entry |
| `build/`, `labreport.pdf` | build products, gitignored |
| `../../tools/labreport/build.py` | the build + rule checker |
| `../../tools/labreport/figures/*.py` | figure data generators (measure from git/tree, never from docs) |
