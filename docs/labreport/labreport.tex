\section*{How to read this report}
\begin{itemize}
  \item \textbf{It is a record, not a rule.} Every entry says what happened in one
    working session: what landed, what was found, what was measured, what is open.
    Rules of record live in \fpath{CLAUDE.md}, \fpath{ROADMAP.md}, the per-phase PRDs
    and the \texttt{bd} tracker; an entry cites them and never replaces them.
  \item \textbf{It is append-only.} A sealed entry is byte-immutable
    (\fpath{MANIFEST.sha256}, checked on every build). A correction to an earlier
    entry is a dated \emph{erratum} in a later one.
  \item \textbf{Every number is measured in its own session}, with the command
    that produced it shown in \measured{grey monospace}. An entry that did not run a
    layer says so rather than inheriting a colour.
  \item \textbf{Findings carry their class}: \fconfirmed, \fleak, \foverdecline,
    \fpreexisting, \fdoc\ --- the same labels the Rule-13 review records use.
  \item \textbf{Budget: at most five pages per session}, measured from the built PDF.
\end{itemize}
