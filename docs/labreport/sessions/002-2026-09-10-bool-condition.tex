\subsection*{Goal}
The owner's scratch program \fpath{example/grover/grover_oracle_uncompute.c} drives a branch phase
from a \texttt{bool} register and declined at the first \texttt{if} (\texttt{branch phase on a bare
i1 condition}); wall~3 of the 2026-09-10 handoff, filed as \bd{test_C_libtooling-3qlq.4}. The
owner's instruction was explicit: no \texttt{int} workaround --- \texttt{bool} and every other type
must work. This session built that increment for the register-free branch phase and measured,
with a probe family, exactly which \texttt{bool}-conditioned shapes now lower and which still decline.

\subsection*{What the shape is}
\texttt{\_Bool b = cq\_theta(b0, }\(\theta\)\texttt{); if (b) cq\_phi(}\(\varphi\)\texttt{);} reaches
the pass as \texttt{br i1 \%b} where \texttt{\%b} \emph{is} the \texttt{cq\_theta\_i1} call: a
one-qubit register, with no compare to mint a flag from. \texttt{clang -O1} produces that from every
natural spelling --- \texttt{if (b)}, \texttt{if (!b)}, \texttt{if (b == 1)} (by successor polarity,
never an \texttt{icmp}), the folded \texttt{if (b) cq\_phi(A); else cq\_phi(B);} (one call whose angle
is a \texttt{select}), \texttt{b \&\& q == 5}, \texttt{b == c} (\texttt{xor i1}), and the owner's
cascade, which IPSCCP collapses to \texttt{br i1 \%b0} outright. On \texttt{main} (\commit{170ede1})
every one of these declined; with \texttt{int b} the same programs compiled through the ordinary
compare-flag mint.

\subsection*{The one design decision worth reading}
A gate that must fire on \texttt{b == 0} is emitted as the \emph{diagonal} \texttt{rz(h\_b, }\(-\theta\)\texttt{)},
never as a \texttt{cqrt\_x} bracket on the register, on
\(X\,P(\theta)\,X = \mathrm{diag}(e^{i\theta},1) = e^{i\theta}P(-\theta)\): the same unitary up to a
global phase (which owner decision D2 already discards), with \texttt{fneg} exact in IEEE. The reason
is not elegance. Three predicates that read the lowered stream depend on ``no non-diagonal gate on a
user register'': the uncompute spine admits an uncontrolled \texttt{cqrt\_rz\_} on a borrowed parent
by name and fails closed on anything else (a bracket would freeze every chain that borrows the
register --- measured discharged instead, \fpath{control_phase_kickback_rail_data_use.ll}); the
chain walk never recovers \texttt{cqrt\_x}; and every wire fence in the classifier argues from that
sentence. Where the emitter's control is an ancilla it minted (a compare flag, a tree node), the
bracket stays exactly as before.

\subsection*{Findings}
\begin{itemize}
  \item \fdoc\ The owner's example changed shape during the session (it is a git-excluded scratch
    file): the version read at session start now compiles (it is the diamond slice above); the
    version on disk at close is the handoff's wall~1, a \emph{dead} \texttt{b1} state-prep arm,
    which is owner question Q4 of the handoff and not a \texttt{bool} issue.
  \item \foverdecline\ (by design, filed) A \texttt{bool} that drives a \emph{data} select or value
    arm (\texttt{if (b) a -= 3;}), an in-place \(R_y\) or state prep (\texttt{if (b) r = cq\_theta(r, }\(\theta\)\texttt{)}),
    or an \(R_y\) angle select declines with one new string, \texttt{bare i1 register condition}:
    \bd{test_C_libtooling-r9e5} (1b-B) and \bd{test_C_libtooling-l4x4} (1b-C).
  \item \foverdecline\ (by design, filed) A loop-\emph{carried} \texttt{bool} (the header phi as the
    condition) and a \texttt{bool} that reaches the next region as a preceding region's merge phi:
    \bd{test_C_libtooling-boi6} (1b-D). A negated rail level in a nest, a NOT inside a tree, and a
    \texttt{trunc}-derived \texttt{i1}: \bd{test_C_libtooling-r903}. All keep the old discriminator string.
  \item \fpreexisting\ A \texttt{bool} \emph{state prep} under control (\texttt{if (c) b = cq\_theta(false, }\(\theta\)\texttt{)})
    still declines at fence F2, because an \texttt{i1} seed always collides with the branch's own
    compare pinned to \texttt{true}/\texttt{false} on its edges --- handoff question Q6, unchanged.
  \item \fpreexisting\ An angle computed \emph{inside} the arm (\texttt{cq\_phi(0.1 * i)} in a loop)
    declines identically for \texttt{int} and \texttt{bool}: the strict one-call arm spelling, not
    this increment.
\end{itemize}
