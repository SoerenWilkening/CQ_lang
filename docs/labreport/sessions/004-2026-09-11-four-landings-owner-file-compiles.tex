\subsection*{Process lessons}
\begin{itemize}
  \item \fdoc\ \textbf{Never relink under a running measurement, and never \texttt{pkill} by an unverified
    pattern.} Two long measurements died or went red for the same self-inflicted reason: rebuilding
    \texttt{cq-opt} makes the binary briefly not exist, and anything holding a path to it fails with
    \texttt{FileNotFoundError} --- a red that reads exactly like an equivalence regression and is not one.
    Separately, a cleanup \texttt{pkill} matched the twin matrix's own temp-dir prefix and SIGKILLed
    children of the \emph{clean} run, and an earlier \texttt{pkill} matched nothing at all because the
    real command line is spelled differently, so a run believed dead competed for CPU for another half
    hour. The fix is mechanical: freeze a copy of the binary for any long sweep, build nothing while a
    suite runs, and verify a kill. bd memory \texttt{never-relink-or-pkill-under-measurement}.
  \item \fdoc\ \textbf{A merge can resurrect a fixture a branch renamed.} Track C committed a decline
    fixture with a written retirement note; Track D had already \texttt{git mv}'d and re-derived it as the
    accept that note predicted. The merge produced one module under two names with contradictory verdicts
    and turned lit red --- which is the merge working. The resurrected copy was deleted, with the
    disposition written into the surviving twin's header so the deletion is not silent, and a whole-corpus
    duplicate-body scan confirmed it was the only merge artefact. bd memory
    \texttt{merge-resurrects-git-mv-fixture}.
  \item \fdoc\ \textbf{Parallel tracks pay for themselves only if every merge re-runs every corpus.} Seven
    source conflicts in the last merge alone, each resolved by reading both sides and recorded with its
    reason, and 778 probe rows re-measured on three binaries afterwards --- which found two things no
    single track could have (the resurrected fixture, and one spelling of the owner's file changing
    disposition across tracks).
\end{itemize}
