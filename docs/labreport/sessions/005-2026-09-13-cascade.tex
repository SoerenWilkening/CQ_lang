\subsection*{Goal}

This session set out to (a) compile that file as written, (b) remove the two neighbouring over-declines the

flat cascade and its loop form, so the owner can choose the loop's spelling with the circuits in front of

them \ldots{} avoid redundancy at each opportunity.''}

\subsection*{What the wall was, measured before any code}
\texttt{clang -O1} if-converts the new line into a data \texttt{select} whose \emph{condition} is the
preparation region's merge \(\varphi\) --- a value the select classifier's leaf grammar did not know (it
admitted a compare or a literal \texttt{cq\_theta\_i1} call). Two measurements on the frozen pre-session
binary decided the shape of the work: \texttt{if (b1) a -= 1;} \emph{already compiled} (the compiler folds a
\(\pm1\) delta to an \texttt{add}, so the \(\varphi\) was already a quantum register to the arithmetic
lowering; only the \texttt{select} consumer was refused), and a hand-written IR twin of ``the module after
the preparation region has emitted'' \emph{already produced the exact 29-line stream} the owner's file
needed. The increment was therefore provably an accept-only widening: no new gate stream, no emitter change
in the tree that mints the merge. The record of that measurement is \fpath{trackM/SCOPE_M.md}; the scoping
also corrected the previous entry's reasoning about this shape (the ``wire fence'' that was thought to be
the second blocker is a blocker only when the arm's rotation is \emph{chained} on the condition's own
register; the owner's preparation is a fresh source, and its wire is clean).

\subsection*{The loop form, scoped}
Two spellings were measured on the pre-session binary, each with its hand-unrolled twin and the state
vector it denotes (\fpath{trackL/SCOPE_loop.md}). \texttt{bool b[N]} --- one qubit per trip, the flat
file's semantics --- has exactly one wall, independent of N: the tainted store into the array, raised before
any loop or control stage runs; rolled, the compiler forbids unrolling, so no small N scalarises. A scalar
\texttt{bool b} re-prepared each trip has four walls in order and, more importantly, denotes a different
circuit: the value arm is conditioned on \texttt{b} rather than on the flag, so on the branch where
\texttt{b} was already set it subtracts again and \texttt{a} goes negative. The recommendation put to the
owner is the array spelling, whose fix needs no new runtime symbol (a rail is an integer handle after
lowering; the array becomes an array of handles in classical memory, and rails stored to memory are frozen).
Beads: \bd{xdu2}, \bd{x5fp}, \bd{ej5w}, the classical-rail-root bead, and a note on \bd{r903} (a carried
\texttt{bool} is an \texttt{i8} wire in every loop form).
