The owner rewrote \texttt{example/grover/grover\_oracle\_uncompute.c} as a rolled loop over
\texttt{bool b0[3]} and it stopped compiling. This session was a diagnosis and design session,
not an implementation one: establish why, establish whether the obstacle is physical or an
engineering decision, settle the design of the fix, and hand the next session a brief. No pass
source was touched.

\subsection*{Findings}
\begin{itemize}
  \item \foverdecline\ The rolled cascade declines \texttt{cq taint escape: tainted value stored
        to memory}. Not a regression: the rolled form has never compiled, and the walls are
        \bd{xdu2} / \bd{wx8g} / \bd{ej5w}, all filed.
  \item The three-wall chain of \texttt{SCOPE\_L1a.md} H1 \emph{holds} on the merged binary.
        W2 in particular is \emph{not} cleared by \bd{wx8g} having landed --- a bank rail has no
        header $\varphi$, so \texttt{railPhiRootMint} finds no mint.
  \item \textbf{Erratum to the scoping:} \texttt{a\_flat\_n3} moved decline$\rightarrow$ACCEPT
        when \bd{om35} landed, so H2's ``\texttt{a\_flat\_n3} declines \texttt{om35}'' is history
        and the hand-unrolled $N{=}3$ twin now exists as a stream reference.
  \item \textbf{No physics anywhere in the blocker.} \texttt{LoopUnrollPrepass}'s U2/U2b are an
        ownership decision stated in the header (the fence is disjoint from every loop the
        rolled-in-place owner claims); W1/W2/W3 are equally decisions. Each trip mints a
        \emph{fresh} rail, so nothing is cloned.
  \item \fconfirmed\ (pre-existing, \bd{s82e}) The target stream leaks six entangled which-path
        rails --- \texttt{h0 h5 h10} (superseded \texttt{a}) and \texttt{h3 h8 h13} (the
        \texttt{a-3} temporaries) --- while stage 2b reports \texttt{0 violation(s)}, because it
        counts \texttt{cqrt\_alloc} \emph{sites} and a rolled per-trip alloc reads as one rail.
        Demonstrated on a real run rather than argued.
  \item Rolled $\neq$ unrolled for this program (50 vs 44 trace lines): \texttt{-O1} folds trip 0's
        guard in the unrolled spelling and cannot in the rolled one. Byte-identity is therefore
        \emph{not available} as this increment's witness.
\end{itemize}
