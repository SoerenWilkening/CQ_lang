A design discussion with the owner, no tracks and no pass code. The owner was not
satisfied with the in-loop results of the previous sessions and proposed a runtime
\emph{taint flag}: for a value whose taint is not known at compile time, branch on a
classical flag between a classical op and a \texttt{cq\_template} op. The session
assessed that proposal against the compiler as it stands, measured the owner's loop
program on a fresh build, and turned the answer into a filed increment and a prompt.

\subsection*{Findings}
\begin{itemize}
  \item \fdoc\ The taint-flag proposal is redundant. Taint is a may-analysis at fixpoint and
        a basis-state rail through reversible templates computes the classical function
        exactly, so a maybe-tainted value can always be lowered as tainted; the flag's
        classical select between handles is already free at runtime, since a handle is an
        \texttt{i32}. What a rolled loop does not know at compile time is \emph{which
        allocation a header $\varphi$ denotes on trip $i$}.
  \item \foverdecline\ The owner's loop program declines at 91:15 (\texttt{control flow
        inside a loop body}, \texttt{ArmClassify.cpp:5478}) while its hand-unrolled twin
        accepts at 45 lines. Read off the stage-1 IR: the header $\varphi$ of \texttt{a}
        has a constant entry incoming (no rail mint, \bd{832l}) and a fresh select-merge
        \texttt{\%out} per trip on its back edge, so \texttt{a} lives on four different
        rails in the flat twin. Neither of the loop layer's two kinds --- a rail crossing
        the back edge in place, or an iteration-local rail --- names it.
  \item \fdoc\ Clang at \texttt{-O1} emits one uniform body (\texttt{llvm.loop.unroll.disable}
        stamped, no peeling), so the rolled form must emit a real compare and strip on trip 1
        where the flat twin's compare is folded to \texttt{true}, and on trip 2 where it is
        folded to $\neg b_0$. Same unitary, different bytes: the witness for this work is a
        per-trip unitary argument plus a quarantined divergence, not identity.
  \item \fconfirmed\ The primary \texttt{cq-opt} was the 2026-09-14 oracle
        (\texttt{0e280fc6}) for three landings before this session's rebuild; a decline
        measured by hand in that window was measured on a stale binary
        (\texttt{CLAUDE.md} \S4c already records this trap from the other side).
  \item \fdoc\ \texttt{bd update --notes} replaces existing notes; one bead's history had to
        be restored from \texttt{dolt\_history\_issues}. Use \texttt{--append-notes}.
\end{itemize}
