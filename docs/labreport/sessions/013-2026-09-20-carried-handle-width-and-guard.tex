\subsection*{Findings}
\begin{itemize}
  \item \fconfirmed\ \textbf{The width record, not the retype, is the safety argument for
        \bd{11qv}, and it was found by reading before implementing.}
        \texttt{logicalOperandWidth} consults \texttt{taint.HandleWidth} \emph{before} the LLVM type
        precisely because the type may be laundered to \texttt{i32}; \texttt{RailBankPromote}'s
        spelling of the same idiom \emph{erases} that entry. Erasing here would let a Q+Q compare
        over two retyped \texttt{i16} $\phi$s recover \texttt{i32} and mint an \texttt{i32} template
        symbol for two \texttt{i16} registers --- verify-clean, links, runs, wrong. Reachability is
        \emph{not} claimed: every Q+Q-under-control shape probed declines identically at both widths
        and the peel moved 0 of 2107 fixtures, so the record is defensive and the source says so.
  \item \foverdecline\ \textbf{A bead that names the next wall is a lower bound, three times in one
        session.} \bd{11qv} named one wall for \texttt{\_Bool}; there are two, and the second
        (\texttt{\_Bool} read as the region's own \emph{condition}) still declines. \bd{h1ip} named
        clause (Z8); clause (Z1) was in front of it. This is \commitref{CLAUDE.md} protocol item~2,
        carried from the previous session, holding again.
  \item \fconfirmed\ \textbf{A correction in \commitref{CLAUDE.md}~\S4e is itself over-general.}
        Round~1 of \bd{zujr} recorded that clause (Z1)'s comment was ``false --- \texttt{-O1} emits
        [a preheader] with a single successor''. Measured on the C spelling of a runtime trip bound,
        \texttt{-O1} emits \emph{no preheader at all}: the guard branches straight into the header.
        Both the original sentence and its correction were over-general; a predicate may not depend
        on which.
  \item \fconfirmed\ \textbf{The composed accept surface is not empty, and the tree's three
        strongest instruments report zero on it} (\bd{4jok}, round~3). Nine C programs compile only
        when \bd{zujr} and \bd{tu9q} P0+P3 are both present --- one of them the owner's own rolled
        cascade plus one line --- while the 2106-fixture corpus A/B finds 0 composition-only movers,
        the 382-cell twin matrix's verdict tables are byte-identical, and all 390 e2e slices agree.
        The fifth consecutive session to file \emph{a composition is not cleared by clearing its
        parts}; the first to exhibit the surface by construction.
  \item \fconfirmed\ \textbf{Pre-existing, not this session's:} a narrow-width \texttt{\_hl} template
        literal reaches the runtime zero-extended (\texttt{253} for $-3$ at \texttt{i8}) because the
        pass emits the operand with no \texttt{signext} while the runtime's C definition takes an
        \texttt{int8\_t} that Clang's ABI marks \texttt{signext}. Attributed by measurement: it
        reproduces on the oracle with a loop-free program that has no carried handle. \bd{ix2v}.
\end{itemize}
