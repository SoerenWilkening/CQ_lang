\subsection*{Goal}
Discharge \bd{4jok}, which was a gate rather than a defect report. Two increments --- \bd{zujr}
(shipped) and \bd{tu9q} P0+P3 (parked on a branch) --- each retire a different clause of one
predicate, and neither retires the other's, so their \emph{conjunction} compiles programs that
neither compiles alone. One of them is the program this project ships, plus one line. The previous
session's independent reviewer exhibited that surface by construction and recorded that every
instrument in the tree reports zero on it: no composition-only movers across 2109 fixtures, the
382-cell twin matrix byte-identical, all end-to-end slices identical. The surface was reachable only
from C sources nobody had committed. The question was whether those programs get a compiler or a
fence.

\subsection*{Findings}
\begin{itemize}
  \item \fdoc\ \textbf{The increment's stated reason for being safe was the wrong reason.} Clause
        (ii-d)'s comment claimed its own \texttt{loopExitDischargePoint} conjunct establishes the
        placement licence. In a nest that is false: the clause asks the predicate of the loop it is
        marking, while the code that actually places the discharge asks it of the outermost enclosing
        loop. The independent reviewer built the shape where those differ --- the grant is made, the
        placement has nowhere to go, and the only thing left standing between that and a silent leak
        is a postcondition in another file, which fires. Safety is real; the argument pointed at the
        wrong member. Corrected at the source, with a fixture pair that is also the multi-exit test
        \bd{tu9q}'s own record calls ``a prediction rather than a test''. On that shape the landing
        is strictly \emph{stricter} than the compiler it replaces.
  \item \fconfirmed\ \textbf{The clearance instrument was unsound, and nine boundary controls did not
        catch it.} The trace checker written for this adjudication built its entanglement graph only
        from arithmetic-template operands, so every permutation gate --- the gates from which every
        merge rail in these programs is built --- produced no edge. It reported ``clean'' on all three
        canonical violations of the no-cloning rule \emph{and} on a real compiled program about which
        the compiler itself emits a warning. It had already reported clean on a real injected defect
        earlier the same day and been fixed once. The reviewer rebuilt it edge-complete with eighteen
        controls and re-established the clearance: 26 traces, one finding, and that one is a loop-free
        program identical on both compilers carrying an already-ruled warning.
  \item \fpreexisting\ A fixture retired by this landing was the only test in 2109 of a fence that
        remains live. One added line to a copy of it restores the test on both compilers.
  \item \foverdecline\ The surface was ten programs, not nine; the tenth had been recorded as
        declining by the previous round on a different pair of binaries.
\end{itemize}

ancestor of \texttt{main}, failing loudly if it is not. Entry 014 was sealed with it.
