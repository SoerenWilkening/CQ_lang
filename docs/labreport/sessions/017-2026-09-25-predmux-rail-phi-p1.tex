\subsection*{Findings}
\begin{itemize}
  \item \fconfirmed\ \textbf{P1, a silent wrong unitary} (\bd{test\_C\_libtooling-41g3}). E6 admitted a
        rail \(\varphi\) \emph{before} the \texttt{dyn\_cast<PHINode>} arm, so it was never
        recorded; for a \(\varphi\) in a non-entry region block \texttt{convertPhis} then
        converts it by the select chain, and \texttt{buildNegation}'s \emph{assertion-only}

        crashing. The arm's cone is dead-swept, so nothing off-grammar survives for a
        downstream owner to object to: \textbf{the silence is structural, not lucky}. Six lines
        of ordinary \texttt{CQ.h} C at the \texttt{-O1} floor; oracle declines loudly, subject
        exits 0 with \textbf{0 bytes of stderr} and emits a circuit in which the inner compare
        is absent and the rail is never a control. \texttt{opt -verify} clean;
        \texttt{free\_pairing\_check.py} \texttt{0 violation(s), 0 unproven}. Fixed by gating the
        admission on the \(\varphi\) being one this flatten will not convert.
  \item \foverdecline\ The fix is a \emph{narrowing}: the interior rail \(\varphi\) it now refuses
        is realizable, so by the 2026-09-11 ruling its decline is compiler structure, not
        physics. The fixture carries the retirement trigger; the route that removes the defect
        rather than hiding it is to \emph{record} the \(\varphi\).
  \item \fconfirmed\ Two P2s on the same conjunct --- \bd{test\_C\_libtooling-woa0} (it is a
        \emph{point-in-time} property: an inner region's flatten makes a terminator

        over-admits exactly the region merge phi, closed by an argument written nowhere).
  \item Increment 5b is \textbf{two} customers, not one, split by \texttt{clang -O1} on whether
        the user also measures the \texttt{bool}. The route was \emph{proved} for one shape
        (a correct, 2b-clean stream built entirely from shipped idioms) and hits a second wall
        in the uncompute spine for the other.
\end{itemize}

\subsection*{Verification run}
Three independent Rule-13 rounds ran (round~2 on the increment, round~3 on the fix), each by an
agent that did not write the change. Round~2 returned \texttt{BLOCKED}; round~3 returned
\texttt{CLEAR-WITH-ITEMS} with \textbf{0 P1}. The orchestrator reproduced the P1 independently
before any fix, and re-verified the fix rather than inheriting it: the M4 build came out
bit-identical to the reviewer's. \texttt{lit} was run separately from the corpus sweeps because
an A/B compares exit codes, strings and emitted IR and \emph{does not evaluate fixture
directives} --- ``0 movers'' was never ``lit is green''. Full \texttt{ctest -j6} was run at the
close. \emph{Not} run: any simulation or statevector (Rule 2), and no \texttt{-O2}/\texttt{-O3}
pipeline.
