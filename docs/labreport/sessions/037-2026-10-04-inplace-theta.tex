\labsessionheader{2026-10-04}{cq\_theta becomes in place only: \texttt{cq\_theta(\&x, $\theta$)}; cq\_ry removed}%
  {ec284441}{n/a}{none}

\subsection*{Goal}
Implement the owner's surface decision of 2026-10-03 (\bd{test\_C\_libtooling-1501}):
\texttt{cq\_theta} is always an in-place operation on its variable, written
\texttt{cq\_theta(\&x, $\theta$)}; the value form \texttt{y = cq\_theta(x, $\theta$)} and the
\texttt{cq\_ry} macro go. The change is header-only. The pass does not change, so
the acceptance test is that the migrated C reaches the pass as the same stage-1 IR.

\subsection*{What landed}
\begin{itemize}
  \item \commit{ec284441} --- \bd{test\_C\_libtooling-1501} ---
  \fpath{include/CQ.h}: \texttt{cq\_theta(px, $\theta$)} is the void expression
  \texttt{*(px) = cq\_theta\_<sfx>(*(px), $\theta$)}, with \texttt{\_Generic} on the pointer
  type; \texttt{cq\_ry} deleted. A side-effecting \texttt{px} (evaluated twice) is a
  compile error: an unevaluated \texttt{\_\_builtin\_assume} whose \texttt{-Wassume}
  diagnostic \texttt{\_Pragma} raises to an error for that expansion. 1,211 call sites

\end{itemize}

\subsection*{Findings}
\begin{itemize}
  \item \fconfirmed\ The macro's shape is load-bearing for stage-1 IR. The issue's
  proposal, an \texttt{always\_inline} wrapper per type, moved the
  \texttt{declare @cq\_theta\_*} line in 475 of 526 comparable modules (the wrapper is
  emitted at the end of the translation unit) and changed more than that in 59
  (\texttt{phi} incoming order, attribute-group numbering). A
  \texttt{do \{\} while (0)} statement form changed predecessor and \texttt{phi} order
  in 61 (114 with a local pointer copy); a statement expression with a local, 63. The
  plain expression keeps the call in the user's function. Recorded as bd memory
  \texttt{inplace-theta-macro-shape-is-ir-load-bearing}.
  \item \fconfirmed\ Two migration traps, both caught by the stage-1 diff: the
  controlling type is now the variable's, so \texttt{\_Bool b = cq\_theta(u, $\theta$)} with
  \texttt{int u} must rotate an \texttt{int} temporary (rewritten naively it rotates a
  1-bit register); and a prep into a memory cell (\texttt{b[i] = cq\_theta(0, $\theta$)} on a
  VLA) must rotate a scalar and store once, or an extra store of the seed survives.
  \item Residual stage-1 differences, explained: 7 modules list two loop
  \texttt{phi}s in another order, because a literal-prep variable now has two stores
  and mem2reg leaves its single-store path; 1 module moves a \texttt{declare}. Lowered
  with \texttt{cq-opt}, the 7 differ only by the same renaming (gate sequence
  unchanged) and the 1 is identical.
  \item Not done: prose in \texttt{.ll} fixture headers, pass-source comments and
  some slice comments still spells C in the retired form (\bd{test\_C\_libtooling-5yla}).
\end{itemize}
