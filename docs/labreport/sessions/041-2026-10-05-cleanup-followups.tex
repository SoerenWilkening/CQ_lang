\subsection*{Findings}
\begin{itemize}
  \item \bd{test\_C\_libtooling-vjdo}: the exemption is sound. The walk it sits in,
  \texttt{reachesObservingSink}, feeds only \texttt{recordIsExemptAt} and from there
  \texttt{warnLiveRecordRotations}. That function emits a \texttt{DS\_Warning}, and both
  call sites in \fpath{CQLoweringPass.cpp} discard its result (checked by the
  coordinator). The exemption can therefore change a warning, never a unitary, a free or a
  decline. The agent measured probes with the cswap row turned into a sink (mutant M3); the
  results matched the baseline on every probe. The park's flag is written to the tape
  directly after the cswap, and that tape write is what exempts the record. Two fixture
  mutants were killed; MISSED 0.
  \item \bd{test\_C\_libtooling-jttf}: two re-derived streams were checked by the
  coordinator. \fpath{lowering\_loop\_phase\_accum\_const.ll}: Ry(0.5), then four in-place
  Ry(0.1) on the one handle, then a measure, with no free. \fpath{lowering\_classical\_mux\_phi\_onereg.ll}:
  an Ry under a classical branch on the same handle, then a measure. Both are correct.
  Three mutants were killed; MISSED 0.
  \item New issues filed from the agents' findings:
  \begin{itemize}
    \item a left-dirty rail leak in a depth-2 phase nest whose inner compare reads the
    source of the outer chain (\bd{test\_C\_libtooling-7xsh}; not r2j3.7, because the chain
    is live);
    \item over-declines \bd{test\_C\_libtooling-x61g} (a park followed by an in-place
    gate), \bd{test\_C\_libtooling-3by9} (any branch phase in the function trips the break's
    phase-answer fence), \bd{test\_C\_libtooling-3paw} (an angle select followed by a
    classical Ry loop), and \bd{test\_C\_libtooling-ptue} (a dead rotated copy of a
    measured register);
    \item a suspected over-warning on the record's own rail (\bd{test\_C\_libtooling-aako});
    \item an owner question about tape writes that precede a gate
    (\bd{test\_C\_libtooling-gl3x});
    \item remaining comment drift (\bd{test\_C\_libtooling-tn85}).
  \end{itemize}
  \item \fpreexisting\ Entry 040's batch edited comments in \fpath{TaintPropagation.h},
  and R15 then requires the \texttt{maintenance} label. That label was not run in entry
  040. It ran this time, and the result covers both batches (Measurements).
\end{itemize}
