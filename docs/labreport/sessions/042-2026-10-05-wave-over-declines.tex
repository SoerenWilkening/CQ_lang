\subsection*{Findings}
\begin{itemize}
  \item \fconfirmed\ \bd{test\_C\_libtooling-g35c} (P1). This silent miscompile was
  reachable from plain \texttt{-O1} C on \texttt{main} \commit{8e9f3382} (coordinator
  re-ran it). \texttt{int z=r; cq\_theta(\&r,.3); for(..)\{cq\_theta(\&r,.1); z=r;\}
  z\^{}=1; return cq\_measure(z);}
  \begin{itemize}
    \item Source semantics: on the zero-trip path the program measures the pre-gate record.
    \item What was emitted: \texttt{ry(h,.3); xorc(h,1); measure(h)}.
    \item Cause: \texttt{staleReadOfValue} skipped chain members before its per-edge
    $\phi$ test.
    \item Found by the 3paw review, round 1. 3paw had added the angle-select spelling.
  \end{itemize}
  \item \fconfirmed\ \bd{test\_C\_libtooling-eqti} (P1).
  \begin{itemize}
    \item ptue's retry, unmerged, reverse-played a kept rail whose adjoint reads a live
    measured register. That adds a gate controlled by that register which the source never
    wrote: by hand arithmetic, $P(q{=}1)$ is 0.0372 in the source and 0.0456 in the emitted
    stream.
    \item The same premise had a pre-existing instance in the 01po.4 QRAM-array borrow,
    reachable from C on the \texttt{main} binary \texttt{50a6f549\ldots}.
    \item Found by the ptue review, round 1. Both instances are fixed.
  \end{itemize}
  \item \fconfirmed\ \bd{test\_C\_libtooling-hk9y} (P2). Pre-existing on \texttt{main}; hand
  IR only (the \texttt{-O1} spelling declines). An in-loop \texttt{xor} of an identity-carried
  record was absorbed as an in-place rail op and applied to the rail on every trip. Found
  by the 3paw review, round 2.
  \item \fconfirmed\ \bd{test\_C\_libtooling-923w} (P1). Latent from C. The counter's
  LCSSA $\phi$ escaped a virtual break carrying its full-trip value, and a phase keyed on it
  was deleted as global. It is now a loud decline (E16). Found by the 3by9 review, round 1;
  3by9 had added the kickback spelling (L9).
  \item \fpreexisting\ \bd{test\_C\_libtooling-cmr9}. Clause 4 exempted a measured record
  that was later re-entangled in place, so a real hazard went unwarned. Found by the
  aako/gl3x review, round 1; fixed.
  \item Precision costs and latent holes filed, not fixed:
  \begin{itemize}
    \item \bd{test\_C\_libtooling-rced}: clause 4 over-warns on read-only uses of a measured
    record.
    \item \bd{test\_C\_libtooling-9128}: clause 4 covers only the current loop instance;
    masked today by a loud decline.
    \item \bd{test\_C\_libtooling-2k72}: over-warning newly reachable through 3by9.
  \end{itemize}
  \item \foverdecline\ Filed from the reviews:
  \begin{itemize}
    \item \bd{test\_C\_libtooling-dm7f.7}: a rolled loop on the parked register after a park.
    \item \bd{test\_C\_libtooling-tinh}: a post-loop phase keyed on the break answer.
    \item \bd{test\_C\_libtooling-8h7d.14}, \bd{test\_C\_libtooling-8h7d.15},
    \bd{test\_C\_libtooling-8h7d.16}: loop shapes.
    \item \bd{test\_C\_libtooling-wt8u}: an angle select, a Case-A loop, then a post-loop
    controlled Ry.
    \item \bd{test\_C\_libtooling-01po.12}: the shared reversal point.
    \item \bd{test\_C\_libtooling-01po.13}: a per-iteration measured parent.
    \item \bd{test\_C\_libtooling-01po.14}: a missed discharge after a break, which is
    warned, not silent.
  \end{itemize}
  \item Disclosure (L9). x61g now admits the \texttt{yiid} measure-then-rotate shape after a
  park. The emitted \texttt{measure(h); ry(h); measure(h)} matches the source.
\end{itemize}
