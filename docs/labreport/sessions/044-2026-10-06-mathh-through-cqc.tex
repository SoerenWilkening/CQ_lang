\subsection*{Goal}
The owner tested math.h calls through \texttt{tools/cqc} and found \texttt{sin} rejected and
\texttt{pow} compiling only at exponents \texttt{2} and \texttt{0.5} (clang rewrites those to a
multiply and \texttt{sqrt}). The session found where the published figure came from, measured
what a user actually gets, and shipped math.h source injection in \texttt{cqc}.

\subsection*{Owner rulings this session}
\begin{itemize}
  \item Purely classical behaviour must not change. This ruled out \texttt{-fno-builtin} on the
  user's file.
  \item Library bodies are lifted, not inlined: a called body must lower exactly as an inlined
  one would, so a decline there is a lifting gap (\bd{p3kd}).
  \item Lifting targets purely classical callees; a lifted callee containing \texttt{cq\_theta}
  may keep declining.
  \item Injection first. Direct Bennett lowering of \texttt{pow}, \texttt{exp} and the like was
  dropped (\bd{3c6m.71} closed); trig keeps CQ's own bodies.
\end{itemize}

\subsection*{Findings}
\begin{itemize}
  \item \fdoc\ The published 131/180 (README: 159/183) was measured by
  \texttt{runtime\_census.py}, which compiled each probe with blanket \texttt{-fno-builtin},
  linked an openlibm corpus built under \texttt{/private/tmp}, force-inlined the bodies and
  reran \texttt{default<O1>}. \texttt{cqc} did none of this; README line 177 said so but kept
  the lab headline. Through \texttt{cqc}: 46/180 (0/120 injected).
  \item \fdoc\ The census guard skipped every \texttt{llvm.*} callee and so could not see
  an unlowered \texttt{llvm.sin.f64}. Found with an R17 mutant: replacing \texttt{cq\_theta} by
  \texttt{freeze} still read COMPILES. Fixed: 18/18 quantum probes now report
  \texttt{unlowered-call} under that mutant.
  \item \fpreexisting\ \bd{r2j3.18}: when a promoted volatile alloca stores a load of another
  one, \texttt{PromoteMemToReg} erases that load while \texttt{deleteDeadCones} still holds a raw
  pointer to it. This caused 29/483 census crashes under \texttt{-j6}, deterministic under
  \texttt{CQ\_OPT\_DEBUG\_ALLOC=lifo}. Reachable from plain C.
  \item \fconfirmed\ (caught before commit) Review rounds 1--3 found seven defects in the new binding, all fixed:
  \begin{itemize}
    \item verify-clean: a TU-private \texttt{static sin} was bound as the program's own;
    \item latent: \texttt{llvm.powi.f80} bound openlibm's private \texttt{powil};
    \item an alias or ifunc \texttt{sin} was missed;
    \item a bound call ending classical could stay on injected source;
    \item an observable rename;
    \item debug-info bloat in classical programs;
    \item an early sweep that internalized bindable bodies.
  \end{itemize}
  \item \foverdecline\ Loud gaps, filed: \bd{p3kd.11} (a math.h call inside a lifted helper is
  not bound); \bd{3c6m.75} (round-2 taint growth is not re-asked).
  \item \fpreexisting\ The lifter's open stale-argument defect \bd{r2j3.6} now reaches every lifted
  math.h call (\texttt{q2=q; cq\_theta(\&q2,.3); cbrt(q)}), which previously failed loudly.
  Disclosed in CLAUDE.md (L9).
\end{itemize}
