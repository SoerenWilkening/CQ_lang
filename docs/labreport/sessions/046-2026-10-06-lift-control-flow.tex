\subsection*{Goal}
\bd{p3kd.7} listed 57 math.h cells (105 probes) whose injected openlibm body the lifter
refused with ``callee contains tainted control flow under quantum lift''. The session
measured why, split the bucket by mechanism and built the two largest pieces. Force-inlining
the same bodies at the top level compiled about 50 of the probes, so most of the bucket was a
lifting gap against the inline twin; the CQ/QC mixtures also fail inlined.

\subsection*{Owner rulings this session}
\begin{itemize}
  \item Classical control inside a lifted body lowers by speculation and a classical choice of
  rail: both arms run, the merge becomes a \texttt{select} between rail handles, the Bennett
  wrap reverses every arm. A per-path wrap was the rejected alternative (bd memory
  \texttt{owner-ruling-clone-classical-control-2026-10-06}).
\end{itemize}

\subsection*{Findings}
\begin{itemize}
  \item \foverdecline\ \texttt{scanBody} was stricter than the emitter it guards: the clone
  path already lowered constant-arm integer selects and tainted switches. Measured with an
  env-gated experiment build before any design work: 13 of 105 probes compiled from that alone.
  \item \fdoc\ A no-\texttt{ret} clone reached \texttt{emitBennettWrap}, which returned false
  silently while \texttt{buildClone} dropped the result (review round 1). Round 2 showed my
  ``unreachable by construction'' comment false: a terminator is a liveness root, so the
  parameter stays live. Now a loud decline with a fixture.
  \item \fpreexisting\ PredMux speculation passes an unreached arm's classical value
  (\texttt{fptosi} out of range, \texttt{shl} by $\ge$ width) unfrozen as a gate's \texttt{\_hl}
  literal to both the forward template and its adjoint; LLVM poison may differ per use. Masked
  today by \texttt{-O0} compilation of the lowered IR. Classical control adds to this
  population. Filed as \bd{p3kd.7.7}; only edge literals and rail-select conditions are frozen.
  \item \fdoc\ L9: more callees lift, so more programs reach the open lifted-call defects
  \bd{r2j3.6} and \bd{r2j3.7}.
\end{itemize}
