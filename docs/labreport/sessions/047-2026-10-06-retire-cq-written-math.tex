\labsessionheader{2026-10-06}{Retiring CQ's own C math: what a ``hand-written'' function means}%
  {b2986d04}{n/a}{none}

\subsection*{Goal}
Earlier today the owner asked to keep only the trigonometric ``hand-written'' functions.
I read that as CQ's own C source for \texttt{sin} (the branchless leaves of bd \texttt{guwr},
2026-07-31). The owner meant a function that lowers to one template call whose reversible
circuit a backend supplies, with Bennett.jl as reference. They found many instructions and no
\texttt{cq\_template\_sin} call in the lowered IR. Nothing in the repository recorded the meaning,
and the shipped bundle still carried CQ-written C. The session wrote the definition down and
removed every CQ-written implementation of a library function (\bd{3c6m.78}).

\subsection*{Owner rulings this session}
\begin{itemize}
  \item A \emph{hand-written} function means a direct route: the compiler emits one call,
  \texttt{cq\_template\_<fn>\_<W>}, and a circuit backend supplies the circuit (Bennett.jl as
  reference, never linked). CQ never writes its own C or IR version of a library function.
  Recorded in CLAUDE.md R14, NORTHSTAR goal 2, \fpath{docs/backend.md} \S7.1, README and bd
  memory \texttt{hand-written-means-backend-circuit}. bd \texttt{guwr} was granted on Bennett's
  \texttt{soft\_sin} circuit but implemented as CQ-written C; it is reversed.
  \item Delete the hand-written C, the CQ-provided census component and the
  \texttt{slice\_branchless\_*} slices.
\end{itemize}

\subsection*{What landed}
\begin{itemize}
  \item \commit{b2986d04} --- \bd{3c6m.78} --- deleted 148 files: the 36 leaves in
  \fpath{tools/library_coverage/branchless/}, 51 \texttt{slice\_branchless\_*} and
  \texttt{slice\_hybrid\_lgammal} slices with their goldens, five lit fixtures compiled from the
  leaves, and the authored-body census (\fpath{inject_census.py}, its outputs,
  \fpath{census_to_tickets.py}). The \texttt{cqc} bundle no longer carries
  \texttt{sin}/\texttt{cos}/\texttt{tan}/\texttt{sinl}/\texttt{cosl}/\texttt{tanl} leaves. Each
  name with a direct route at a width (read from \fpath{tools/intrinsic_table.yaml}) forwards to
  its intrinsic (\texttt{wprobe.direct\_shims}), so a lifted openlibm body that calls
  \texttt{sin} or \texttt{atan} on a \texttt{double} reaches the one-call lowering. The census
  tools lost the CQ-provided row, its A/B re-probe and its gate.
\end{itemize}
