correction, used zero tests, builds or targeted probes. R1 exposed inner
\texttt{noundef} argument obligations, constant RAUW scope, entry producers,
recursive proof walks, effective \texttt{noreturn} and duplicated predicates.
R3 exposed calling-convention mismatch, nested call poison flags, intrinsic
immediate-UB contracts and the risk of a vacuous declaration range proof.
The shared owner now checks those contracts and uses visited proof worklists.

R3's follow-up found an untaken \texttt{xor(q,poison)} arm whose erased source
marker left a single raw gate literal. The result escaped, so there was no
second literal slot for the existing pairing guard to catch. The correction
normalizes selected scalar source operand Uses with one entry freeze per typed
constant per function, before handle lowering. Surviving speculative producers
and admitted call arguments get a non-poison proof without use/path assumptions
or a stable freeze. Within-function forward and inverse uses share that SSA
value. Separate clone/twin invocations retain their existing undef fence.
