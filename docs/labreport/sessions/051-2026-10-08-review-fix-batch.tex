\subsection*{Findings (R11 rounds 3--5)}
Round 3 used three independent reviewers on the snapshot binary (six probes each).
Rounds 4 and 5 reviewed only the delta of the preceding fixes. Every round found
something, and two of the three UB holes were introduced by the preceding round's fix.
\begin{itemize}
\item \fconfirmed\ (IR-only, round 3) \bd{bwfp}: an unproven value-constraining
\emph{return} attribute (\texttt{range}, \texttt{nofpclass}) on an inner callee
or on the hoisted call site makes poison that reached a \texttt{noundef} sink. The
round-2 code declined it by accident; the round-3 rewrite reopened it. Now a poison
source; three decline fixtures (\texttt{\dots\_retattr\_*}).
\item \fconfirmed\ (IR-only, round 4): admitting \texttt{returned} as inert let a
false \texttt{returned} ``prove'' a false \texttt{range}, because LLVM's known bits
read the call as its argument. This was a new PredMux accept relative to
\commit{e0af16ed}. \texttt{returned} is now admitted only when every \texttt{ret}
returns that parameter; two decline fixtures.
\item \fconfirmed\ (IR-only, round 5): LLVM~19 \texttt{canCreateUndefOrPoison}
answers ``no poison'' for a \texttt{noundef} ctlz/cttz/abs whatever its poison flag.
The round-4 range proof removed the accident that had declined ctlz/cttz. Now
asked of \texttt{curatedIntrinsicCanBePoison}, as \texttt{totalCall} does.
\item \foverdecline\ (round 3, fixed): clang's \texttt{noundef range(i32 1, 3)}
on \texttt{x > 0 ? 1 : 2} and \texttt{range(i32 0, 10)} on \texttt{x \% 10u}
were unproven by known bits alone, and a multi-TU \texttt{returned} parameter was
refused. The range proof now intersects \texttt{computeConstantRange} with known
bits in both signednesses. (Round 4) LLVM~19 stamps a call-site
\texttt{range(i32 0, 33)} on ctpop/ctlz/cttz; it is now proven from the
intrinsic's semantics. Accept fixtures plus a narrowed-range decline twin.
\item \foverdecline\ (round 5, filed \bd{dm7f.21}, P1): ordinary C that
\commit{e0af16ed} accepted now declines loudly when a poison-capable value reaches
a \texttt{noundef} sink inside the hoisted callee. Example:
\texttt{int f(int x)\{return g(x+1);\}} (for \texttt{x = INT\_MAX} the hoisted call is
immediate UB on basis states the guard excluded). Provable flags (\texttt{nneg}
casts, \texttt{trunc nuw}) are also still treated as poison. The census below
contains none of these shapes.
\item \fpreexisting\ filed: integer-only switch twins of W8 decline
(\bd{dm7f.19}); PredMux's strict call path declines popcount, abs and an inlined
\texttt{+1u} that the 6.5 path accepts (\bd{dm7f.20}); \texttt{blockPred} ORs a
grouped case's predicate twice (\bd{4bnd}).
\item Instrument (R17): the stage-2b census built its ``returned'' set module-wide
by local name, so a dirty template rail in \texttt{main} counted as returned when
another function returned a value of the same name (reviewer probe: census 0, true
1). Now per function; the self-test gained that case and a pin for the clone-data
clause. Both mutants were killed.
\item The census renderer took the first stderr line containing ``error'', which
since \bd{3c6m.82} is the note (``the error below is inside \dots''). It now takes
\texttt{error:}, as \fpath{probe.py} does.
\item \fdoc\ \texttt{LiftDiagnostics}: nested scopes would print each note twice, and
\texttt{HasErrors} stayed on the wrapper; both are latent and now fixed. Comments
corrected in \fpath{ArmClassify.cpp}, \fpath{ControlDetect.cpp} (W8 claims only when
E2--E7 pass), the trig fold (single-host libm assumption) and the narrow slice.
\end{itemize}

\textbf{Owner ruling (R14, \bd{3c6m.81}).} A quantum \texttt{exp10} of every spelling,
including a user-written GNU \texttt{exp10}, lifts openlibm's real \texttt{pow}
as \texttt{pow(10, x)}. The numerical contract is openlibm \texttt{pow(10,x)}, which
can differ from the system \texttt{exp10} in the last ulp. It is recorded in bd
memory \texttt{exp10-binds-pow-owner-ruling}.

\textbf{Disclosures (L9).} Clones now derive their taint through main's propagation
and inherit its sticky/settle machinery (\bd{r2j3.19}). W8 admits FP switches
inside a loop body, which leaves garbage rails allocated (the fixture header says
so). \bd{bwfp} adds declines of shapes \commit{e0af16ed} accepted (above,
\bd{dm7f.21}). The narrow-ABI fix changed one golden:
\fpath{slice_loop_carried_handle_narrow} lines 7, 22 and 37, \texttt{65533}
$\to$ \texttt{-3} (the same i16 bits; regenerated deliberately, diff checked to be
exactly those three lines).

\subsection*{Verification run}
Red for the new fixtures was shown by hand (\texttt{cq-opt} plus FileCheck)
against the snapshot binary of each round. Green was one lit invocation whose
filter selected 874 of 2738 fixtures, with no failure reported (quiet mode prints no
per-category counts). It was followed by one ctest invocation over 200 entries
(clone, libm, classical-call, switch and PredMux slices, runtime, the stage-2b
self-test, both census sync gates). 199 passed; \texttt{e2e-census-headline-sync}
failed as expected, since the pages still said 86/180. After the census and
\texttt{probe.py render} the script reports four pages matching 100/180.

Mutation: four lit invocations aborted at configuration and ran no fixture, because
lit's stale-binary guard refused when only \texttt{cq-opt} had been rebuilt. Then
four real mutants (unverified \texttt{returned}, unchecked intrinsic range, the
curated poison flag dropped, the note's same-function test dropped) each ran only
their killing fixture: all killed, \textbf{MISSED 0/4}. The green run is the no-op
control. After restoring the sources, the rebuilt \texttt{cq-opt} reproduced the
pre-mutation hash.

The full census ran once with the final binary (\texttt{-{}-jobs 6}, 6\,min wall).

The batch gate ran once. \measured{ctest -{}-test-dir build -LE maintenance -j6}
passed 548 of 550 entries in 727\,s, and
\measured{cmake -{}-build build -{}-target cq-opt-equivalence-full} compared 2738
fixtures with 0 mismatches. The two failures:

the map was regenerated.
\item \texttt{ir-pass-lit}: 2735 passed, 1 expected failure and 2 failures. Both are
