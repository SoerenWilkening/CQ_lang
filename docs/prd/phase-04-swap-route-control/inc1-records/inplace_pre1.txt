#   150 cells whose Ry side ALSO carries a NON-ARM `cq_phi` — `base=phial`

#       the `aliasmeas` / `launder` / `phi_after` / `route2` / `invert` consumers:
#          78 PHI-UNLOWERED · 63 DECLINE-BOTH-DIFF · 9 DECLINE-BOTH.
#       Under `void` each of those becomes a plain ALIAS plus an UNCONTROLLED
#       branch phase, so `phial` degenerates to `src`, `aliaseq` to `eq` and
#       `aliasmeas` to a second measure of the same register. After Increment 1,
#       D2 DELETES the uncontrolled call and those degeneracies are the cells'
#       real meaning — a `void` run in which one of them differs from its
#       degenerate sibling means the D2 deletion did not happen.
#
# THE 78 `PHI-UNLOWERED` ROWS ARE A DISPOSITION, NOT A HARNESS ERROR. A
# pre-Increment-1 binary has no concept of `void @cq_phi(double)`: it neither
# lowers nor deletes the call, which SURVIVES into the lowered IR and cannot link
# (no such runtime symbol, and this epic adds none — PRD D3). MEASURED on
# 52d7764. The instrument reads the LOWERED IR (never the trace — there is no
# trace) and skips stages 2b/3/4. Every note reports BOTH sides and says which
# was never asked: `ry 2 residual, rz not asked (declined)`. AFTER INCREMENT 1
# THIS VERDICT MUST NOT APPEAR.
#
# ⚠ ONE INVARIANT NOTE, AND IT IS PRE-EXISTING AND SURFACE-INDEPENDENT.
# `c_src_ne_ifelse_meas_i32` trips
#     INV : I2 negated controlled rotation: cqrt_ry_i32_controlled(h2, h1, -0x1p-1)
# and REPRODUCES VERBATIM ON THE REGISTER SURFACE on this same oracle binary
# (measured, single-cell run). -0.5 is 0.4 - 0.9, i.e. the drbq Increment-2b
# BY-DIFFERENCE angle, not an adjoint. The I2 invariant's stated premise — "every
# angle in this generator is positive, so a negative one can only have been
# synthesized [by EmitInverse]" — has been FALSE since Inc 2b. Reported, NOT
# fixed here: it is not this epic's to decide.
#
# WHAT THE DIFF SHOULD LOOK LIKE AFTER INCREMENT 1
#   * the 232 RY-ONLY rows move to PREFIX-IDENTICAL. Under `void` the comparison
#     is "the same stream except the ONE gate line" (`reduce_kickback`
#     canonicalises both stems' arm gate to `cq_arm_gate(<flag>, <angle>)`), so
#     PREFIX-IDENTICAL there means: same flag mint, same `cqrt_x` bracketing,
#     same position, same angle, same strip, same free — with the Rz side firing
#     `cqrt_rz_i1(f, T)` where the Ry side fires
#     `cqrt_ry_<W>_controlled(f, r, T)`.
#     ⚠ AND WHAT THAT DOES *NOT* WITNESS: the kickback line names NO register, so
#     the prefix comparison can no longer see that the controlled Ry named the
#     ROTATED RAIL. That is policed by the invariants on the raw Ry trace (I1
#     count, I3 no free of a rotated rail, I6 no adjoint across the rotation) and
#     by the lit family — not by a green prefix. Do not quote it as such.
#   * the 78 PHI-UNLOWERED rows get a real verdict (D2 deletes the call).
#   * a row landing on PREFIX-MISMATCH is a FINDING.
#   * `cfg=ifelse` / `ifelse2` rows are expected to differ by MORE than one gate
#     line and must not be read as findings: PRD §3 gives the void Rz stem the
#     EXACT two-gate angle select (no subtraction, run-time arms admitted) while
#     the Ry stem keeps the Inc-2b by-difference form. Different lowerings, by
#     design.
