## What Phase 3 inherits

- A width-parametric pipeline that compiles `quantum T` for every
  Phase-2 type and lowers `+` to per-width `cq_template_add_<W>[_hl]`.
- A 36-fixture LIT corpus pinning IR-pass behavior per ABI width.
- A 21-fixture e2e corpus pinning byte-exact runtime traces.
- 28 frontend intrinsic decls + 28 runtime decls + 14 template decls
  (with `_hl` variants) as the stable Phase-2 ABI.
- A single architectural mechanism for adding operators: extend
  `OpcodeLowering.cpp` (currently `add` / `fadd` only) with the new
  opcode → template mapping. No new files needed for Phase 3's
  `-` / `*` / `&` / `|` / `^` additions.
