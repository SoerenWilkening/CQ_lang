Coverage has **two orthogonal axes** (bd e4jv). **Lowering** = *every* applicable classical/quantum (C/Q) argument mixture lowers, links, runs, **and** matches a committed golden trace — the compiler emits the right reversible-template call sequence. But the runtime is **trace-only** (each `cq_template_*` just prints its symbol; measure returns 0), so "verified" certifies the lowering, **not** that a correct reversible *implementation* of those templates exists. **Backend** is that second axis: a static per-fn tier — 🟩 `standard` (reversible routine directly obtainable), 🟨 `synthesizable` (buildable IEEE bit-field circuit, not off-the-shelf), 🟥 `open` (no known elementary reversible circuit: the transcendentals — the bulk of the math.h count). **Backend-available** = 🟩 standard **and** it lowers. A third level, backend-*correctness* (does it compute the right unitary), needs simulation and is deferred (owner, 2026-06-10). A loud decline is a *correct* (uncovered) outcome — never papered over to inflate a number (Prime Directive); the backend column exists to stop the single-number overclaim that a *compilable* fn has a *working reversible backend*.

The summary table, the per-library detail page, the `goldens/<slug>/` dir, and the README badge all regenerate automatically. After an adversarial correctness audit (Rule 13), commit goldens with `python3 tools/library_coverage/probe.py bless --lib <name>`.

Each `B(...)`/`St(...)` also carries a **`backend=`** tier (🟩 `standard` · 🟨 `synthesizable` · 🟥 `open` · `n/a`) — a static per-fn judgment of the emitted templates' reversible-backend availability, orthogonal to whether the fn lowers. Omitting it defaults to the safe under-claiming `open`; the four tiers must partition the total or `summarize()` asserts loudly.
