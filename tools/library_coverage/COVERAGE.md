## Adding a library

Append a `Lib(name, include, slug, blurb, fit, SPEC)` entry to `LIBRARIES` in `probe.py` (define its `SPEC` list like `MATHH_SPEC`), then run `python3 tools/library_coverage/probe.py run`. The summary table, the per-library detail page, the `goldens/<slug>/` dir, and the README badge all regenerate automatically. After an adversarial correctness audit (Rule 13), commit goldens with `python3 tools/library_coverage/probe.py bless --lib <name>`.

Each `B(...)`/`St(...)` also carries a **`backend=`** tier (🟩 `standard` · 🟨 `synthesizable` · 🟥 `open` · `n/a`) — a static per-fn judgment of the emitted templates' reversible-backend availability, orthogonal to whether the fn lowers. Omitting it defaults to the safe under-claiming `open`; the four tiers must partition the total or `summarize()` asserts loudly.
